# 학습 진도와 세션 인계

이 파일은 실제 학습 상태의 기준이다. 커리큘럼 작성이나 코드 존재만으로 실험을 완료 처리하지 않는다.

## 지금 위치

- 과정: F00 — 환경 확인 전.
- 현재 주제: [첫 시작 안내](START-HERE.md), 이어서 [CPU](../src/main/java/com/shinkwang/backendsystemlab/cpu/README.md).
- 현재 세부 단계: 실험할 Linux 환경과 실제 Java 실행 환경 확인.
- 도움 수준: 안내형. 개념·명령·볼 항목을 먼저 설명한다.
- 확인된 작업: 2026-10-15 학습 원칙과 커리큘럼 문서 작성. 실험 코드는 추가하지 않음.
- 학습자가 실제 수행한 실습: 이 저장소에 확인 가능한 기록 없음. 과거 대화에서 언급된 실습은 완료로 추정하지 않음.
- 아직 확인하지 못한 점: VM 준비, JDK/도구 버전, 앱 기동, 학습자가 이미 익힌 명령어.
- 최근 실제 실험 기록: 없음.
- 다음 작은 행동: 터미널의 실행 위치와 OS를 확인하고 `docs/ENVIRONMENT.md`의 환경 E01부터 채운다.

## 세션 종료 시 갱신할 항목

```text
날짜:
환경 ID:
오늘 진행한 세부 단계 ID:
실제로 실행하고 관찰한 것 / 기록 링크:
학습자가 자기 말로 설명한 것:
틀렸던 예상과 수정한 이해:
아직 모르는 점 / 막힌 지점:
도움 수준: 안내형 / 힌트형 / 독립형
다음에 할 작은 행동 하나:
```

다음 세션은 마지막 행동부터 이어간다. 최근 이해 수준을 확인할 필요가 있으면 지난 출력의 항목 하나를 다시 읽어보는 정도로 시작하고, 이미 끝낸 전체 과정을 반복하지 않는다.
