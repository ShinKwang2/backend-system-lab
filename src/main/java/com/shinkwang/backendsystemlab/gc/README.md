# GC / 할당과 Heap OOM

객체 생성·보관, GC 활동, 응답 지연을 연결하고 JVM Heap OOM의 증거를 읽는다.

전체 위치와 순서: [CURRICULUM.md](../../../../../../../docs/CURRICULUM.md) · [현재 진도](../../../../../../../docs/PROGRESS.md)

## 시작 조건

Memory 입문과 MEMORY-03, Thread 덤프 읽기. 실제 GC 종류·Heap 설정을 먼저 확인한다.

## 첫 설명

객체를 만들면 Heap 공간을 사용한다. 더 이상 필요한 참조가 없는 객체의 공간은 GC가 회수할 수 있다. 객체를 계속 보관하는 경우와 잠깐 만들고 버리는 경우를 비교하면서 배운다.

## 도구를 처음 사용할 때

아래 표는 명령어 사전이다. 첫 수업에서는 필요한 명령 하나와 출력 항목 2~3개만 소개한다. `<PID>`, `<PORT>`, `<PATH>`, `<실험경로>`는 실제 값으로 바꾸는 자리 표시자이며 그대로 실행하지 않는다. 아직 없는 API나 설정은 해당 단계에서 함께 만든다.

| 명령·도구 | 목적과 입력 | 처음 읽을 항목·종료 |
| --- | --- | --- |
| `jcmd <PID> VM.flags` / `GC.heap_info` | 실제 JVM 플래그와 Heap 정보를 출력한다. 명령은 하나씩 실행한다. | Heap 크기·GC 관련 설정과 Heap 변화. 출력 후 종료. |
| GC 로그 | 실험 JVM 시작 옵션에 `-Xlog:gc*`를 추가하는 방법부터 배운다. | GC 시각·종류·pause·전후 Heap. 로그 파일 경로와 크기 제한을 함께 정한다. |
| `curl` / `top` | 같은 구간의 응답 시간과 CPU를 비교한다. | 요청 시각·경과 시간·CPU. GC 로그 시간 기준과 맞춘다. |

## 세부 커리큘럼

### GC-01 — 할당과 회수

- 배울 것: 참조·도달 가능성·회수, 실제 수집기의 기본 구조를 배운다. 세대 구분은 사용하는 수집기에 맞춰 설명한다.
- 안내 실습: 객체 일시 생성과 계속 보관을 작은 부하로 비교하고 GC 로그와 Heap 추이를 읽는다.
- 예상·가설 질문: 할당량과 실험 후 남아 있는 객체 양은 같은 뜻일까?
- 완료 기준: 로그 한 구간을 읽고 할당·보관·회수를 구분한다.

### GC-02 — Heap 크기와 압박

- 배울 것: Heap 상한, 할당 속도, GC 빈도와 pause를 배운다.
- 안내 실습: 정상 기준을 먼저 기록하고 동일한 작업에서 Heap 크기만 바꿔본다. 격리 환경에서 작은 단계로 조정한다.
- 예상·가설 질문: GC가 자주 일어나는 것과 API가 느린 것은 어떻게 검증해야 연결할 수 있을까?
- 완료 기준: 동일 부하의 Heap·GC·지연을 비교하고 인과를 단정하지 않는 가설을 적는다.

### GC-03 — GC와 지연 구분

- 배울 것: stop-the-world와 GC의 동시 작업, CPU 소비와 멈춤 시간을 구분한다.
- 안내 실습: 요청 타임라인과 GC 로그를 대조한다. 보관량이나 할당량을 줄인 뒤 같은 요청 조건으로 재검증한다.
- 예상·가설 질문: 응답 지연 시점이 GC와 겹친다는 것만으로 충분할까?
- 완료 기준: 변경 전후의 증거와 남은 다른 가능성을 설명한다.

### GC-04 — JVM Heap OOM

- 배울 것: OutOfMemoryError가 발생하는 영역과 실패 처리, Heap OOM 증거를 배운다.
- 안내 실습: 별도 실험 프로세스에서 Heap 상한과 보관량을 통제해 Java heap space 오류를 재현한다. 종료·덤프 크기·정리 방법을 먼저 정한다.
- 예상·가설 질문: OOM 메시지는 어떤 영역을 말할까? 오류가 났다고 JVM 전체가 반드시 즉시 종료될까?
- 완료 기준: 실제 오류 메시지·프로세스 상태·JVM 옵션을 기록한다. 호스트/cgroup OOM과의 비교는 Container에서 한다.

## 해석할 때 지킬 경계

GC 결과는 JDK·수집기·Heap·부하에 따라 다르다. 작은 Heap이면 반드시 특정 지연이 생긴다고 약속하지 않는다. 강제 GC나 heap dump가 관측 대상에 영향을 줄 수 있음을 배운 뒤 필요할 때만 사용한다.

## 수업과 기록

각 단계에서 기초 설명 → 정상 관찰 → 예상 → 조건 하나 변경 → 실제 관찰 → 가설과 검증 → 정리 순서로 진행한다. 도구 입문은 장애 주입이나 해결이 없어도 된다. 첫 실험은 안내형, 반복 실험은 힌트형, 마지막 적용은 독립형으로 도움을 줄인다.

실제 출력과 자기 설명은 [실험 기록 양식](../../../../../../../docs/EXPERIMENT-TEMPLATE.md)으로 남긴다. 현재 이 문서는 계획이며 어떤 단계도 완료로 표시하지 않는다. 다음 단계는 고정된 날짜가 아니라 실제 관찰과 이해를 확인한 뒤 선택한다.
